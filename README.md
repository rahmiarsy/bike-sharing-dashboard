# Bike Sharing Dashboard ✨

## Setup Environment - Anaconda
Buka Anaconda Prompt dan arahkan ke folder utama `submission`, lalu jalankan perintah berikut:
```bash
conda create --name main-ds python=3.9
conda activate main-ds
pip install -r requirements.txt
```

## Setup Environment - Shell/Terminal
Buka terminal dan arahkan ke folder utama `submission`, lalu jalankan perintah berikut:
```bash
pipenv install
pipenv shell
pip install -r requirements.txt
```

## Run Streamlit App
Pastikan terminal masih berada di dalam folder utama `submission`, lalu jalankan perintah berikut untuk memulai dashboard:
```bash
streamlit run dashboard/dashboard.py
```
